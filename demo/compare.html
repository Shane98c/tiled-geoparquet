Why the style menu has two groups

The GeoParquet file holds the full table of features and, beside it, a light copy of their shapes for drawing the map at each zoom.

Fast. These columns were also copied into the map part when the file was built. Colouring by one fetches a small extra piece for the tiles in view, at any zoom.

Slower zoomed out. These columns were not copied, because a copy would be large: unique ids, and text with many distinct values. The map looks each feature up in the full table instead, which is cheap zoomed in and heavy zoomed out.

Either way nothing is rebuilt: any column of the table can colour the map. A PMTiles archive holds the columns chosen when its tiles were cut, in every tile.

Synchronized views; counts include tile boundary copies, not unique buildings. Different thinning and overzoom rules still apply. A request cancelled before its response began is not counted; one cancelled after counts at its full size. Times run from the end of a move.
